# Roadmap

The live list is the repository's open issues: `from-coaching` (gaps a real coaching answer hit, worked
daily by the build project) first, then the older backlog, labelled by type (`bug`, `foundation`,
`design`, `data`) and priority (`P1` do next, `P2` soon, `P3` later). This file keeps no copy of that list,
so it can't go stale. What already shipped: [CHANGELOG.md](../CHANGELOG.md); the state at the
coaching/build split: [HANDOFF.md](HANDOFF.md).

Work on a branch per issue and reference it in the commit (`Fixes #n`). How to develop: [DEVELOP.md](DEVELOP.md).
